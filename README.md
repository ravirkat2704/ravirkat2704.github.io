# Ravi Kenchanagoudar — Developer Portfolio

Personal portfolio built with React, Vite and Motion. Showcases Laravel/PHP/MySQL projects, skills, education and contact details.

**Live site:** https://ravirk2704.github.io/ *(update to your real URL)*

## Run locally
```bash
npm install
npm run dev        # development
npm run build && npm run preview   # test the production build
```

## Edit content
All text, links and projects live in `src/data/site.js`.
Put screenshots in `public/images/<project-folder>/` and your CV at `public/resume.pdf`.

## Deploy
Push to `main` — GitHub Actions builds and publishes automatically (Settings → Pages → Source: GitHub Actions).
